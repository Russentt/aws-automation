# AWS Automation.

## Idea.

I was enrolled in a standard Cloud Computing class. So, I found myself frequently asked to deploy Amazon EC2 instances, and alike AWS services. Since my computer is prone to have performance issues, AWS website usually had (for me) quite delayed responses. That made me curious about whether there was a way to handle the tasks my course required me to do in a more efficient manner. I discovered something that, thinking seriously about it, was not a big suprise: aws-cli lets you speed up mundane tasks related to aws services deployment. I had to read some documentation, learn about getopt in Bash, and I finally came up with a small set of simple scripts to go through my assignments with ease.

## Usage.

`./<aws-resource>-make.sh`

* Note: scripts require parameters.
