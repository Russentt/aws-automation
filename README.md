# AWS Automation

## Idea

I was enrolled in a regular Cloud Computing class. So, I found myself frequently deploying Amazon EC2 instances, and similar AWS services. Since my computer is prone to have performance issues, AWS website usually had (for me) quite sluggish responses. That made me curious about whether there was a way to handle the tasks my course required me to do in a more efficient manner. I discovered something that, thinking seriously about it, was not a big surprise: aws-cli lets you speed up aws services deployment tasks. I had to read some documentation and learn about getopt in Bash. Finally I came up with a small set of simple scripts that made my assignments easier and faster to complete.

## Usage

`./<aws-resource>-make.sh`

* Note: these scripts require parameters.
